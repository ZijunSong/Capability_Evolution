# SCAPE H100-3 下一步：Independent KL / Scorer Verification

## 任务定位

H100-3 本轮作为独立测量审计节点，不做新的 component ranking。利用现有 HF continuation-logprob scorer 和 same-state snapshots，独立验证 H20 的 KL/JS/token logprob metric。

```

```

## 1. 独立实现

建立：

```text
scripts/audit_independent_tool_kl.py
```

只依赖 torch / transformers / tokenizer。禁止 import H20 Stage-L evaluator、旧 `L_m` helper 或 tournament aggregator，避免共因 bug。

## 2. 输入

各选 256 states：

```text
Evidence Graph
Subtractive
Importance
Verify
```

保持同一 `snapshot_hash`、full/reduced prompt、tool-token spans。

## 3. 独立计算

对每 token 计算：

```text
KL(T||S)
KL(S||T)
JS
cross entropy
teacher NLL
student NLL
signed logprob gap
```

验证 KL/JS 非负，并与 torch/scipy reference 对账。
