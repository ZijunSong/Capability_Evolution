# 5. Targeted event mining

只有 natural CONFIRM128 中 event support 低时才做。

规则：

```text
natural result 与 targeted result 分开报告
```

可按 component 定义：

```text
evidence_graph:
  graph non-empty / graph mature states

subtractive_curation:
  curated set size >= threshold
  candidate pool has replace/remove opportunity

importance_tagging:
  multiple candidate docs with differing relevance/importance

auto_populate:
  first-search / first-curate boundary

verify:
  verify-eligible claim/evidence conflict state
```

禁止人工改 label；只是筛 state。
