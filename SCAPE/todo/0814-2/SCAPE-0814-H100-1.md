# 9. 最终判定

### `DIRECT_RUNTIME_COMPRESSION`

若：

```text
Q(R_knee) non-inferior to Q(R7)
AND
runtime cost materially lower
```

这是当前最有价值的结果：

> 不需要 weight migration，也能通过重新分配 capability representation 获得更轻 Harness。

### `HYBRID_RUNTIME_BOUNDARY`

若：

```text
state-only 明显低
minimal renderer 恢复明显
full renderer 增益边际很小
```

则给出：

```text
state: runtime
minimal semantic renderer: runtime/context
graph-aware weight migration: current checkpoint not learnable
```

### `FULL_RENDER_REQUIRED`

若 full 显著优于所有 minimal：

说明 renderer 也是当前不可压缩 runtime dependency。
