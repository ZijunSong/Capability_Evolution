```text

Runtime:
render tokens / latency
```

冻结：

```text
CLEAN_GH_CAL128
seed=8141
```

### 进入训练的必要条件

至少需要：

```text

V3 没有系统性比 V2 更差
```

如果 clean base 上：

```text

```

则 Evidence Graph 不再是 clean-setting target；等待 H100-2 的 downstream-advantage handoff，选择其 value-positive component。

禁止为了“必须训 Evidence Graph”而硬训无 gap 数据。
