# 8. Objective 判定

### `DIRECT_TOOL_DISTRIBUTION_BETTER`

要求：

```text
route_kl:
  JS_name_post < pre
  两 seed一致
  CE 不系统恶化
  invalid_tool_rate 不升

且相对 legacy name-only：
  JS improvement 更稳定
```

### `TOKEN_OBJECTIVE_OK`

若 route_kl 并不优于 legacy，而两者在独立 evaluator 都表现相近：

说明 objective mismatch 假设不成立。

### `NO_OBJECTIVE_RESCUE`

若：

```text
route_kl overfit / heldout 也 FAIL
```

则更支持：

```text
released Harness-1 checkpoint placement boundary
```
