# 8. 最重要的论文解释

如果大量出现：

```text
HIGH_I_LOW_VALUE
```

则说明：

> Same-State Influence 只回答“Harness 是否改变 policy”，不能回答“这种改变是否值得迁移”。

于是 SCAPE Pre-stage 应解释成四个不同问题：

```text
Contribution:
component 对系统有用吗？

Influence:
component 改变 policy 吗？

Value:
这种改变在当前 state 上有 downstream benefit 吗？

Learnability:
这种有价值的改变能进 weights 吗？
```

不要再试图让一个 I_m 同时承担后三个含义。
