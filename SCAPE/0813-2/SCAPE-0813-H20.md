# SCAPE H20 下一步：Learnability Metric / Trainer Audit（最高优先级）

## 0. 为什么暂停新的 capability migration

最新 true-SCAPE 中，所谓 `d_pre/d_post divergence` 多次为负数，例如 SC/IT/VT micro tournament 中 `d_pre=-0.1344/-0.0464/-0.1731`。如果 D 真的是 KL/JS divergence，这在数学上不成立；同时 `L_m=1-D_post/D_pre` 在负值区间失去原有解释。因此当前“四个组件都不可学”的结论必须先区分：真实负结果，还是 metric / sign / reduction / mask / trainer 实现问题。

本轮禁止新 8K、Stage S、Stage M。

## 2. 建立 canonical metrics

必须同时实现并记录：

```text
M1 = KL(T || S) >= 0
M2 = KL(S || T) >= 0
M3 = JS(T,S)   >= 0
M4 = signed teacher-student logprob gap（允许负，但不得叫 divergence）
```

允许数值误差下限 `-1e-7`。

## 7. Go / No-Go

### AUDIT_PASS
必须同时满足：

```text
KL/JS 非负
evaluator == trainer metric
64-state true-teacher overfit 能显著降低 canonical KL
shuffled control 不出现相同改善
```

然后才恢复 capability Learnability。

### AUDIT_FAIL
若连 64-state frozen teacher 都无法降低 KL：停止所有 migration，先修 trainer。
