# B2. 分层

对每 state 标记：

```text
turn bucket:
  early
  middle
  late

student executed tool:
  search
  grep
  read
  review
  curate
  verify
  end

teacher preferred tool:
  same categories

disagreement:
  name change
  args-only
  no meaningful change

argument class:
  query text
  doc ids
  add/remove ids
  importance value
  claim text
  termination reason
```

---

# B3. 统计

每个 component 报：

```text
I_name by tool
I_args by argument class
teacher entropy
student entropy
tool-name disagreement
args-only disagreement
top-10 highest influence state archetypes
```

特别关注：

### evidence_graph

是否主要作用于：

```text
curate
review
verify
end_search
```

如果主要是 arguments：

H20 不能只训练 tool name。

### importance_tagging

是否主要改变：

```text
curate importance values
add/remove ids
```

若 tool name 基本不变而 args 变化：

Candidate B 更应使用 argument-token OPD。

### verify_tool

确认其 influence 是：

```text
真正改变 verify routing
```

还是只是：

```text
verification-related context 改变其他工具参数。
```
