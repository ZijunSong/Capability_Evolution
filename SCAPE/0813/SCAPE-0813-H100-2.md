# 1. 新增 Same-State Short-Horizon Utility Probe

对于 reduced Harness rollout 产生的真实 state：

```text
xi_t
```

构造：

```text
reduced view
full view
```

得到：

```text
a_S = reduced-view policy action
a_T = full-view policy action
```

只在：

```text
a_S != a_T
```

或 tool/argument divergence 高于 threshold 的 state 上进入 utility probe。

从同一个 `xi_t` fork：

```text
Branch S:
  execute a_S
  then policy continues K steps

Branch T:
  execute a_T
  then same policy continues K steps
```

建议：

```text
K = 2
K = 4
```

禁止 Full Harness 后续接管。

这不是 teacher trajectory。

# 7. Candidate-B decision

只允许以下结论：

### Strong B
满足：

```text

+
short-horizon branch T > branch S
+
系统 contribution 不明显冲突
```

如果：

```text

但 short-horizon utility ~ 0
```

```text
Harness 改了很多行为，但没带来可见收益
```

不优先蒸馏。

如果：

```text
只在 targeted event 有收益
自然任务 support 极低
```

可作为 hybrid/conditional runtime，不作为主 B。
