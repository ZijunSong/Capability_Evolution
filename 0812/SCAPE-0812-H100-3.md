# B2. 真 logits/logprob scorer

禁止继续使用：

```text
deterministic_offline_stub
```

实现真实模型 scorer。

### Tool-name distribution

合法 tool names：

```text
fan_out_search
search_corpus
grep_corpus
read_document
review_docs
curate
verify
end_search
```

对每个 tool name 计算 conditional sequence logprob，然后归一化为：

```text
P(tool_name | view)
```

计算：

```text
I_name = JS(P_full || P_reduced)
```

### Argument influence

1. 从 Full view greedy decode teacher tool call；
2. 固定 teacher call 的 argument key/value token；
3. 分别在 full/reduced view teacher-force；
4. 计算：
   - `I_arg_key`
   - `I_arg_value`
   - mean token KL/JS

若 vLLM 当前接口不能可靠 score arbitrary continuation：

优先尝试 canonical HF scorer；
允许 HF/vLLM 两套 backend 做 5-state parity。

**不允许退回 heuristic 字符串差异冒充 logits。**
